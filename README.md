## 준비

```bash
pip install -r .claude/skills/법인세-검토에이전트/requirements.txt
```

본인 PC 전역에 쓰려면 `.claude/skills/법인세-검토에이전트` 폴더를 `~/.claude/skills/` 로 복사합니다.
